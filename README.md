### 👋 About

에이전트가 실제로 일하는 개발 환경을 만듭니다. 터미널, 워크트리, DAG 오케스트레이션 쪽을 주로 팝니다.

- 🔭 지금은 **Paseo / OmO** 에이전트 워크플로우 작업 중
- 🦀 Rust + Tauri 로 네이티브 툴링, TypeScript 로 UI
- ⚡ 관심사: 병렬 에이전트, GPU 렌더링 터미널, 개발자 경험
